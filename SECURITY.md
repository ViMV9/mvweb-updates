# Security Policy

## Supported Versions

Only the latest released version of each plugin receives security updates.
Plugins auto-update through this repository, so keeping plugins up to date
ensures you always run the supported version.

## Reporting a Vulnerability

If you discover a security vulnerability in any MVweb plugin, please report it
privately — **do not** open a public issue.

- **Email:** mvweb.ru@gmail.com
- **Subject:** `Security: <plugin name>`

Please include:

- Affected plugin and version
- A description of the issue and its impact
- Steps to reproduce (proof of concept if possible)

We aim to acknowledge reports within 5 business days and to ship a fix as soon
as a remediation is validated. Please give us reasonable time to release a fix
before any public disclosure.

## Поддерживаемые версии

Обновления безопасности получает только последняя выпущенная версия каждого

Если вы обнаружили уязвимость в каком-либо плагине MVweb, сообщите о ней
приватно — **не** создавайте публичный issue.

- **Email:** mvweb.ru@gmail.com
- **Тема письма:** `Security: <название плагина>`

Укажите, пожалуйста:

- Затронутый плагин и его версию
- Описание проблемы и её последствий
- Шаги для воспроизведения (по возможности — proof of concept)

исправление сразу после проверки решения. Пожалуйста, дайте нам разумное время
на выпуск исправления до публичного раскрытия.
